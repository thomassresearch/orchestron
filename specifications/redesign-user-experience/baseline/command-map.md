# Current Perform commands and their redesign destinations

This is the migration checklist for milestone 1. Rows group gestures that operate on the same musical object. The linked component and reference in each row carry the individual fields, gestures, and device-specific limits. “Current” refers to the React application at `fd7cdc0`. The destination column describes the approved design.
